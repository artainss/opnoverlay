# opnoverlay

Личный оверлей для Windows на Rust: запись экрана, откаты, скриншоты и управление звуком. Версия 0.5 доступна для локальной сборки; проект продолжает развиваться.

## Текущее состояние

Работает основа записи экрана и окон с аппаратным H.264, MP4, откаты в памяти или временных файлах, скриншоты PNG/JPEG, настройки и галерея. Функции и совместимость с конкретными играми, полноэкранным режимом и античитами требуют дополнительной проверки. В галерее доступны просмотр видео и изображений, обрезка видео с возможностью вернуть оригинал и удаление в корзину. Захват звука отдельных приложений и показатели производительности требуют дополнительной проверки в реальных сценариях. Необязательный счётчик FPS использует PresentMon; для трассировки Windows могут понадобиться права администратора или членство в группе Performance Log Users.

По умолчанию: Alt+Z — меню, Escape — закрыть меню, Alt+F1 — скриншот, Alt+F9 — запись, Alt+F10 — сохранить откат. Сочетания можно изменить в настройках. Для новых настроек длительность отката — 45 секунд, качество — «Максимум деталей», исходное разрешение и 60 FPS. Ранее сохранённые значения остаются без изменений.

## Сборка для Windows

Нужны Rust и Cargo не ниже версии, указанной в `Cargo.toml`, а также инструменты сборки Visual C++ для MSVC.

```powershell
cargo build --release --locked
cargo test --locked
```

Исполняемый файл: `target/release/opnoverlay.exe`. Для счётчика FPS при ручном запуске положите `third-party/presentmon/PresentMon.exe` рядом с ним; установщик и переносимый архив включают его вместе с лицензией. Установщик собирается отдельно с помощью WiX; инструкция находится в `installer/build.ps1`.
