# opnoverlay

**Русский** | [English](README.en.md)

Игровой оверлей для Windows на Rust. Сохраняет последние секунды игры, записывает экран и звук, делает скриншоты и позволяет просматривать и обрезать клипы прямо в оверлее.

## Установка

Скачайте MSI или переносимый ZIP со [страницы выпусков](https://github.com/artainss/opnoverlay/releases/latest). MSI обновляет установленную версию с сохранением настроек и галереи. Для ZIP распакуйте все файлы в доступную для записи папку и запустите `opnoverlay.exe`. Рядом с архивом и MSI опубликованы контрольные суммы SHA-256.

- **Alt+Z** открывает и закрывает панель. **Escape** возвращает назад или закрывает панель.
- **Alt+F10** сохраняет откат. **Alt+F9** начинает и останавливает запись. **Alt+F1** делает скриншот.
- **Настройки → Видео** выбирают экран или отдельное окно. Если сохранённое окно закрыто, выберите источник перед записью.
- **Настройки → Запись** управляют качеством, длительностью и лимитом буфера. **Настройки → Звук** включают микрофон, звук рабочего стола и отдельные дорожки.

## Текущее состояние

Работает основа записи экрана и окон с аппаратным H.264, MP4, откаты в памяти или временных файлах, скриншоты PNG/JPEG, настройки и галерея. Функции и совместимость с конкретными играми, полноэкранным режимом и античитами требуют дополнительной проверки. В галерее доступны просмотр видео и изображений, обрезка видео с возможностью вернуть оригинал и удаление в корзину. Захват звука отдельных приложений и показатели производительности требуют дополнительной проверки в реальных сценариях. Необязательный счётчик FPS использует PresentMon; для трассировки Windows могут понадобиться права администратора или членство в группе Performance Log Users.

По умолчанию: Alt+Z — меню, Escape — вернуться назад или закрыть меню, Alt+F1 — скриншот, Alt+F9 — запись, Alt+F10 — сохранить откат. Сочетания можно изменить в настройках. Для новых настроек длительность отката — 45 секунд, качество — «Максимум деталей», исходное разрешение и 60 FPS. Ранее сохранённые значения остаются без изменений.

В opnoverlay 0.8 раздел «Настройки → Запись» показывает битрейт и оценку размера записи и отката. Экономный профиль использует до 720p при 30 FPS. Галерея ищет по имени, проигрыватель перематывает на 5 секунд, а редактор позволяет задавать границы по текущей позиции и сдвигать их шагом 10 мс. Экспорт обрезки привязан к кадрам.

В 0.9 в разделе «Настройки → Запись» можно сохранить именованные профили игровой записи с источником, качеством, FPS, параметрами отката и микрофона. Применение профиля подтверждается кнопкой «Сохранить». Для дискового буфера можно задать лимит от 128 до 16 384 МиБ. При достижении лимита приложение сокращает историю отката.

В Windows общий звуковой микс по умолчанию записывается в одну дорожку. Опция «Отдельные звуковые дорожки» сохраняет общий микс, звук рабочего стола или выбранных приложений, затем микрофон. Обрезка сохраняет все дорожки. При начальной настройке можно запустить трёхсекундную тестовую запись без звука и скопировать результат с названием захвата и кодировщика. Тестовый файл удаляется после проверки.

Режим «Только выбранные приложения» записывает выбранные процессы и их дочерние процессы. Микрофон работает отдельно. После перезапуска приложения в микшере можно подтвердить новый процесс и сохранить прежнюю громкость и состояние отключения звука.

Главная панель открывается на дисплее активного окна. Для захвата всего экрана опция «Сохранять растяжение экрана» заполняет кадр с пропорциями рабочего стола при временной смене разрешения. При выключенных откатах, записи и предпросмотре постоянный захват не работает. Во время захвата видимость рамки зависит от Windows.

В настройках видео можно включить DXGI для захвата экрана без записи указателя. Для захвата окна и временного разрешения используется захват Windows. При смене режима во время записи текущий клип сохраняется отдельно и захват возобновляется на том же дисплее. DXGI проверен на RTX 3050 с одним монитором. Для нескольких мониторов, других видеокарт и игр требуется отдельная проверка.

## Сборка для Windows

Нужны Rust и Cargo не ниже версии, указанной в `Cargo.toml`, а также инструменты сборки Visual C++ для MSVC.

```powershell
cargo build --release --locked
cargo test --locked
```

Исполняемый файл: `target/release/opnoverlay.exe`. Для счётчика FPS при ручном запуске положите `third-party/presentmon/PresentMon.exe` рядом с ним; установщик и переносимый архив включают его вместе с лицензией. Установщик собирается отдельно с помощью WiX; инструкция находится в `installer/build.ps1`.

Для локальной разработки на Windows с Python 3.11+ используйте `python tools/check.py quick` для тестов с компактным кэшем, `build` для сборки и `smoke` для короткого захвата текущего экрана с проверкой записи, отката и PNG. `media` проверяет существующий MP4. Тестовые медиа удаляются после проверки. Команда `release` собирает MSI, переносимый ZIP и файл контрольных сумм SHA-256 с WiX и cargo-about. Параметры доступны через `python tools/check.py --help`.

Для переносимого запуска распакуйте ZIP в доступную для записи папку, закройте другие экземпляры opnoverlay и запустите `opnoverlay.exe`. Файл `opnoverlay.portable` включает хранение настроек в `Data` и новых файлов по умолчанию в `Media` рядом с программой. Автозапуск Windows для переносимой сборки отключён.
